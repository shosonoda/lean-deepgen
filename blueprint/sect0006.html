6.2 Balancing depths and balanced rates (Appendix I, the four regimes EL, EP, PL, PP; lem:balancing, eq:tradeoff-table)

Theorem 378

def:bias-exp LeanDeepgen.Tradeoff.biasExp_antitone For \(\alpha {\gt} 0\), \(k \mapsto e^{-\alpha k}\) is nonincreasing.

Proof ▼

\(\exp \) is monotone and \(k \mapsto -\alpha k\) is nonincreasing.

Theorem 379

def:bias-poly LeanDeepgen.Tradeoff.biasPoly_antitoneOn For \(\beta {\gt} 0\), \(k \mapsto k^{-\beta }\) is nonincreasing on \((0,\infty )\).

Proof ▼

Power with a nonpositive exponent is antitone on the positive reals.

Theorem 380

def:var-log LeanDeepgen.Tradeoff.varLog_monotoneOn For \(n \ge 0\), \(k \mapsto \sqrt{\log k / n}\) is nondecreasing on \((0,\infty )\).

Proof ▼

\(\log \) is monotone on \((0,\infty )\); divide by \(n \ge 0\) and take square roots.

Theorem 381

def:var-poly LeanDeepgen.Tradeoff.varPoly_monotoneOn For \(\gamma \ge 0\) and \(n \ge 0\), \(k \mapsto \sqrt{k^{\gamma }/n}\) is nondecreasing on \((0,\infty )\).

Proof ▼

\(k \mapsto k^\gamma \) is monotone for \(\gamma \ge 0\); divide by \(n\) and take roots.

Theorem 382

def:gen-bound LeanDeepgen.Tradeoff.max_le_genBound If \(\mathsf{bias}\ge 0\) and \(\mathsf{var}(\cdot ,n) \ge 0\) on a set \(S\) of depths, then \(\mathsf{gen}(k,n) \ge \max \{ \mathsf{bias}(k), \mathsf{var}(k,n)\} \) for every \(k \in S\).

Proof ▼

Each summand is bounded by the sum because the other one is nonnegative.

Theorem 383

def:gen-bound LeanDeepgen.Tradeoff.balancing Balancing principle. Let \(S \subseteq \mathbb R\) be a set of depths on which \(\mathsf{bias}\ge 0\) is nonincreasing and \(\mathsf{var}(\cdot ,n) \ge 0\) is nondecreasing. If \(k_0 \in S\) balances the two terms, \(\mathsf{bias}(k_0) = \mathsf{var}(k_0,n)\), then \(\mathsf{gen}(k,n) \ge \mathsf{bias}(k_0)\) for every \(k \in S\), while \(\mathsf{gen}(k_0,n) = 2\mathsf{bias}(k_0)\); hence \(k_0\) minimizes the bound over \(S\) up to the factor \(2\).

Proof ▼

Case split on \(k \le k_0\) or \(k \ge k_0\): in the first case \(\mathsf{bias}(k) \ge \mathsf{bias}(k_0)\) and \(\mathsf{var}(k,n) \ge 0\); in the second \(\mathsf{var}(k,n) \ge \mathsf{var}(k_0,n) = \mathsf{bias}(k_0)\) and \(\mathsf{bias}(k) \ge 0\). The identity at \(k_0\) is the balance equation.

Theorem 384

def:bias-poly,def:k-pp LeanDeepgen.Tradeoff.biasPoly_kPP For \(\beta ,\gamma {\gt} 0\) and \(n {\gt} 0\), \(\mathsf{bias}({k^{\ast }}) = {k^{\ast }}^{-\beta } = n^{-\beta /(2\beta +\gamma )}\).

Proof ▼

\((n^{1/(2\beta +\gamma )})^{-\beta } = n^{-\beta /(2\beta +\gamma )}\) by the power rule.

Theorem 385

def:k-pp,def:var-poly LeanDeepgen.Tradeoff.varPoly_kPP For \(\beta ,\gamma {\gt} 0\) and \(n {\gt} 0\), \(\mathsf{var}({k^{\ast }},n) = \sqrt{{k^{\ast }}^{\gamma }/n} = n^{-\beta /(2\beta +\gamma )}\).

Proof ▼

\({k^{\ast }}^\gamma / n = n^{\gamma /(2\beta +\gamma ) - 1} = n^{-2\beta /(2\beta +\gamma )}\), and the square root halves the exponent.

Theorem 386

def:bias-poly,def:k-pp,def:var-poly,def:gen-bound LeanDeepgen.Tradeoff.tradeoff_PP PP regime (??). Let \(\beta ,\gamma {\gt} 0\) and \(n {\gt} 0\). At the balancing depth \({k^{\ast }}= n^{1/(2\beta +\gamma )}\), \(\mathsf{gen}({k^{\ast }},n) = {k^{\ast }}^{-\beta } + \sqrt{{k^{\ast }}^{\gamma }/n} = 2\, n^{-\beta /(2\beta +\gamma )}\), and for every depth \(k {\gt} 0\), \(\mathsf{gen}(k,n) = k^{-\beta } + \sqrt{k^{\gamma }/n} \ge n^{-\beta /(2\beta +\gamma )}\). Thus \({k^{\ast }}\) is optimal up to the factor \(2\) and \(\mathsf{gen}({k^{\ast }},n) \asymp n^{-\beta /(2\beta +\gamma )}\).

Proof ▼

lem:var-poly-monotoneOn,lem:bias-poly-kpp,lem:bias-poly-antitoneOn,lem:balancing,lem:var-poly-kpp Both terms equal \(n^{-\beta /(2\beta +\gamma )}\) at \({k^{\ast }}\) (theorem 384, theorem 385), so the balancing principle theorem 383 on \(S = (0,\infty )\) gives both claims.

Theorem 387

LeanDeepgen.Tradeoff.eventually_log_le_mul For every \(c {\gt} 0\), \(\log x \le c\, x\) for all sufficiently large \(x\).

Proof ▼

\(\log x = o(x)\) (Mathlib: ‘Real.isLittleO_log_id_atTop‘).

Theorem 388

LeanDeepgen.Tradeoff.eventually_log_log_le_mul For every \(c {\gt} 0\), \(\log \log n \le c \log n\) for all sufficiently large \(n\).

Proof ▼

lem:eventually-log-le-mul Compose theorem 387 with \(\log n \to \infty \).

Theorem 389

LeanDeepgen.Tradeoff.log_lt_self_of_pos \(\log x {\lt} x\) for \(x {\gt} 0\).

Proof ▼

\(\log x \le x - 1 {\lt} x\).

Theorem 390

LeanDeepgen.Tradeoff.rpow_neg_half_mul_rpow_half For \(n {\gt} 0\) and \(L \ge 0\), \(n^{-1/2} L^{\gamma /2} = \sqrt{L^{\gamma }/n}\).

Proof ▼

\(\sqrt{L^\gamma /n} = \sqrt{L^\gamma }/\sqrt n = L^{\gamma /2} n^{-1/2}\).

Theorem 391

LeanDeepgen.Tradeoff.sqrt_mul_div For \(c \ge 0\), \(\sqrt{c\, x/n} = \sqrt c\, \sqrt{x/n}\).

Proof ▼

Multiplicativity of the square root.

Theorem 392

def:rate-ep LeanDeepgen.Tradeoff.rateEP_nonneg \(n^{-1/2}(\log n)^{\gamma /2} \ge 0\) for \(n \ge 1\).

Proof ▼

Product of two nonnegative powers.

Theorem 393

def:bias-exp,def:rate-ep,def:k-ep LeanDeepgen.Tradeoff.biasExp_kEP For \(\alpha {\gt} 0\) and \(n {\gt} 1\), \(e^{-\alpha {k^{\ast }}} = n^{-1/2}(\log n)^{\gamma /2}\) exactly.

Proof ▼

\(-\alpha {k^{\ast }}= -\tfrac 12 \log n + \tfrac \gamma 2 \log \log n\); exponentiate.

Theorem 394

def:k-ep LeanDeepgen.Tradeoff.kEP_le For \(\alpha , \gamma {\gt} 0\) and \(\log n \ge 1\), \({k^{\ast }}\le \log n/(2\alpha )\).

Proof ▼

\(\gamma \log \log n \ge 0\) when \(\log n \ge 1\).

Theorem 395

def:var-poly,def:rate-ep,def:k-ep LeanDeepgen.Tradeoff.varPoly_kEP_le For \(\alpha ,\gamma {\gt} 0\), \(n {\gt} 1\), \(\log n \ge 1\) and \(\gamma \log \log n \le \log n\): \(\sqrt{{k^{\ast }}^{\gamma }/n} \le \sqrt{(2\alpha )^{-\gamma }}\; n^{-1/2}(\log n)^{\gamma /2}\).

Proof ▼

lem:sqrt-mul-div,lem:rpow-neg-half-mul-rpow,lem:kep-le \(0 \le {k^{\ast }}\le \log n/(2\alpha )\), so \({k^{\ast }}^\gamma \le (2\alpha )^{-\gamma } (\log n)^\gamma \); divide by \(n\) and take roots.

Theorem 396

def:var-poly,def:bias-exp,def:rate-ep,def:gen-bound,def:k-ep LeanDeepgen.Tradeoff.eventually_EP_bounds For \(\alpha ,\gamma {\gt} 0\), eventually in \(n\): \(n^{-1/2}(\log n)^{\gamma /2} \le \mathsf{gen}({k^{\ast }},n) \le \bigl(1 + \sqrt{(2\alpha )^{-\gamma }}\bigr)\, n^{-1/2}(\log n)^{\gamma /2}\).

Proof ▼

lem:eventually-log-log-le-mul,lem:bias-exp-kep,lem:var-poly-kep-le The bias term equals the rate exactly (theorem 393) and the variance term is at most \(\sqrt{(2\alpha )^{-\gamma }}\) times the rate (theorem 395); the side conditions hold for large \(n\) by theorem 388.

Theorem 397

LeanDeepgen.Tradeoff.isTheta_of_eventually_bounds If \(0 \le g\) eventually, \(c {\gt} 0\), and \(g \le f \le c\, g\) eventually, then \(f = \Theta (g)\).

Proof ▼

Both \(O\)-directions, with constants \(c\) and \(1\).

Theorem 398

def:var-poly,def:bias-exp,def:gen-bound,def:k-ep LeanDeepgen.Tradeoff.tradeoff_EP EP regime (??). Let \(\alpha ,\gamma {\gt} 0\) and \({k^{\ast }}(n) = \frac{1}{2\alpha }(\log n - \gamma \log \log n)\). Then \(\mathsf{gen}({k^{\ast }},n) = e^{-\alpha {k^{\ast }}} + \sqrt{{k^{\ast }}^{\gamma }/n} \asymp n^{-1/2}(\log n)^{\gamma /2}\) as \(n \to \infty \) (more precisely, between \(1\) and \(1 + (2\alpha )^{-\gamma /2}\) times the rate).

Proof ▼

lem:eventually-ep,def:rate-ep,lem:isTheta-of-eventually-bounds,lem:rate-ep-nonneg Apply theorem 397 to the two-sided bound theorem 396.

Theorem 399

def:var-poly,def:bias-exp,def:gen-bound,def:k-ep LeanDeepgen.Tradeoff.tradeoff_EP_isBigO EP regime, upper bound: \(\mathsf{gen}({k^{\ast }},n) = O(n^{-1/2}(\log n)^{\gamma /2})\).

Proof ▼

thm:tradeoff-ep The \(O\)-half of theorem 398.

Theorem 400

def:k-el,def:bias-exp,def:rate-el LeanDeepgen.Tradeoff.biasExp_kEL For \(\alpha {\gt} 0\) and \(n {\gt} e\), \(e^{-\alpha {k^{\ast }}} = \sqrt{\log \log n/n}\) exactly.

Proof ▼

lem:rpow-neg-half-mul-rpow \(-\alpha {k^{\ast }}= -\tfrac 12\log n + \tfrac 12\log \log \log n\); exponentiate and rewrite \(n^{-1/2}(\log \log n)^{1/2} = \sqrt{\log \log n/n}\).

Theorem 401

def:k-el LeanDeepgen.Tradeoff.kEL_bounds For \(\alpha {\gt} 0\) and \(\log n \ge e\): \(0 {\lt} {k^{\ast }}\le \log n/(2\alpha )\) and \(\log {k^{\ast }}\le \log \log n + |\log (2\alpha )|\).

Proof ▼

lem:log-lt-self-of-pos \(\log \log \log n \ge 0\) gives the upper bound; \(\log \log \log n {\lt} \log \log n {\lt} \log n\) gives positivity; then \(\log {k^{\ast }}\le \log (\log n/(2\alpha )) = \log \log n - \log (2\alpha )\).

Theorem 402

def:k-el,def:var-log,def:rate-el LeanDeepgen.Tradeoff.varLog_kEL_le For \(\alpha {\gt} 0\) and \(\log n \ge e\): \(\sqrt{\log {k^{\ast }}/n} \le \sqrt{1 + |\log (2\alpha )|}\, \sqrt{\log \log n/n}\).

Proof ▼

lem:sqrt-mul-div,lem:kel-bounds \(\log {k^{\ast }}\le \log \log n + |\log 2\alpha | \le (1 + |\log 2\alpha |)\log \log n\) because \(\log \log n \ge 1\) (theorem 401).

Theorem 403

def:k-el,def:bias-exp,def:var-log,def:rate-el,def:gen-bound LeanDeepgen.Tradeoff.eventually_EL_bounds For \(\alpha {\gt} 0\), eventually in \(n\): \(\sqrt{\log \log n/n} \le \mathsf{gen}({k^{\ast }},n) \le \bigl(1 + \sqrt{1 + |\log (2\alpha )|}\bigr)\sqrt{\log \log n/n}\).

Proof ▼

lem:var-log-kel-le,lem:bias-exp-kel Bias equals the rate (theorem 400); variance is at most \(\sqrt{1 + |\log 2\alpha |}\) times the rate (theorem 402).

Theorem 406

def:bias-poly,def:k-pl LeanDeepgen.Tradeoff.biasPoly_kPL For \(\beta {\gt} 0\), \(n {\gt} 0\) and \(L = \log (2\beta n) {\gt} 0\): \({k^{\ast }}^{-\beta } = \sqrt{L/(2\beta n)}\).

Theorem 407

\(\log \) of a power and of a quotient.

Theorem 408

def:k-pl LeanDeepgen.Tradeoff.kPL_balance The PL balancing equation \(k^{2\beta }\log k \asymp n\) holds exactly up to the factor \(1 - \log L/L\): for \(\beta {\gt} 0\), \(n {\gt} 0\) and \(L = \log (2\beta n) {\gt} 0\), \({k^{\ast }}^{2\beta }\log {k^{\ast }}= n\, (1 - \log L/L)\).

Proof ▼

lem:log-kpl \({k^{\ast }}^{2\beta } = 2\beta n/L\) and \(\log {k^{\ast }}= (L - \log L)/(2\beta )\) (theorem 407); multiply out.

Theorem 409

def:k-pl LeanDeepgen.Tradeoff.kPL_balance_tendsto \({k^{\ast }}^{2\beta }\log {k^{\ast }}/ n \to 1\) as \(n \to \infty \), i.e. \({k^{\ast }}^{2\beta }\log {k^{\ast }}\sim n\).

Proof ▼

lem:tradeoff-pl-balance By theorem 408 the ratio is \(1 - \log L/L\) with \(L = \log (2\beta n) \to \infty \), and \(\log L / L \to 0\).

Theorem 410

def:var-log,def:k-pl LeanDeepgen.Tradeoff.varLog_kPL_le For \(\beta {\gt} 0\), \(n {\gt} 0\) and \(L = \log (2\beta n) \ge 1\): \(\sqrt{\log {k^{\ast }}/n} \le \sqrt{L/(2\beta n)}\).

lem:log-kpl \(\log {k^{\ast }}= (L - \log L)/(2\beta ) \le L/(2\beta )\) since \(\log L \ge 0\).

Theorem 411

\(\log (2\beta n) = \log 2\beta + \log n\) and \(-|c| \le c \le |c| \le |c|\log n\).

Theorem 412
